# Rights, licensing, and citation

This repository combines platform-generated notebook exports, model-derived visualizations, browser screenshots, author-defined AOIs, and added supporting scripts and documentation. They do not all have the same provenance.

## Third-party material

The embedding dataset identifies the **OlmoEarth Artifact License**, not MIT. Consult the dataset's linked license and the platform user agreement for the relevant source material:

- https://source.coop/olmoearth/olmoearth-v1-3-embeddings
- https://olmoearth.allenai.org/eula

The dataset license alone does not establish the license of every platform-exported notebook or screenshot. Mapbox, OpenStreetMap, Sentinel-2 / Microsoft Planetary Computer, and Maxar credits identify distinct displayed layers; preserve applicable attribution and review the original terms. See `docs/THIRD_PARTY_NOTICES.md` for the evidence inventory.

## Author-controlled material

No new blanket reuse license has been selected for this mixed collection. The author can choose an appropriate license for material they control and state its scope explicitly, without relicensing upstream content. A public GitHub repository is not by itself a substitute for a reuse license.

## Citation

Please cite the manuscript, the exact release or commit used, and the upstream data/model as applicable. This is an academic citation request, not a claim that MIT compels citation of a paper. MIT requires preservation of copyright and license notices; it does not require scholarly citation.

Official references:
- https://choosealicense.com/licenses/mit/
- https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files

No root MIT `LICENSE` is supplied because a repository-wide MIT grant would incorrectly imply one uniform authorization for this collection. Choose a scoped license after establishing control of the relevant components.
